How it works

No clipping, no account, no cloud. Just read — the note appears on its own.

01

Capture

Tracks the frontmost app/window via Accessibility, with a ScreenCaptureKit + Vision OCR fallback when there's nothing else to read.

02

Filter

Only counts it once you've dwelled ~20s and ~150 words — quick app switches never create noise.

03

Dedup & thread

URL canonicalization, content hashing, SimHash and embedding similarity catch duplicates and link related reads into one thread.

04

Summarize

A local LLM fills in the title, summary, key points, "why it matters" and tags in the background.

The AI models it uses

Downloaded once on first launch. Nothing is sent to a server after that.

JobModel
Summarization title, summary, key points, tagsQwen3.5 0.8B Q4_K_M, via llama.cpp
Dedup & similarity catches rereads and related threads; also embeds imagesEmbeddingGemma 2 UD-Q4_K_XL + mmproj, via llama.cpp

Both run locally over llama-server on localhost — no network calls beyond the one-time model download.

Private by design

  • No account, no cloudThere's nothing to sign up for and no server that sees what you read.
  • Everything on-deviceCapture, OCR, and summarization all run locally — no analytics, no cloud APIs.
  • Denylisted apps are skippedMail, Messages, Terminal, and password managers are never read.

Questions

Do I need internet?

Only once, to download the two AI models on first launch. After that MicroLog works fully offline.

Does it read everything I look at?

No. It only turns a window into a note after you've dwelled on it for ~20 seconds and it has ~150+ words, and it skips denylisted apps like Mail, Messages, Terminal and password managers entirely.

What happens if I reread the same article?

The dedupe engine recognizes it via URL canonicalization, content hashing, SimHash and embedding similarity, and skips creating a duplicate note.

Does it work on Intel Macs?

MicroLog targets Apple Silicon Macs.

Is it really free?

Yes, and open source under the MIT license.
